# Marketplace-da-economia-criativa
Aplicação web fullstack que conecta artesãos e empreendedores criativos de Pernambuco  a compradores de todo o país. A plataforma dá vitrine e canal de venda a quem produz, valorizando técnica, origem e história de cada peça, e oferece recomendação de produtos, busca por técnica/região e indicadores de venda.
